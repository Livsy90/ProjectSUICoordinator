# SwiftUI Coordinator

A fully developed iOS application built with **SwiftUI** and structured around the **MVVM + Coordinator** architecture pattern.

This project demonstrates a practical, production-ready approach to navigation and flow management in SwiftUI using coordinators, while keeping views lightweight and testable.
